# Setup Python

## Simple Method

Mu is a brilliant IDE designed for people new to Python, visit the [Mu site](https://codewith.mu/) to download it.
    It includes all of the libraries

## No Installation

Another option, if you don’t want to install anything, is to use an online IDE, e.g. [Repl.it](https://replit.com/).

## Advanced

You can install python yourself by visiting the [download page](https://www.python.org/downloads/).

To install external packages, follow [this guide](https://packaging.python.org/en/latest/tutorials/installing-packages/).

This includes the IDLE editor, but more advanced Ninjas may prefer [PyCharm](https://www.jetbrains.com/pycharm/) or [Visual Studio Code](https://code.visualstudio.com/).
